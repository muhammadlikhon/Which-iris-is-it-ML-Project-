    What happens when you open this page

    1. Split the flowers. 120 go to training and 30 are locked away for the final exam, with the same mix of species in each group.
    2. Compare two models. Logistic regression draws smooth boundaries between species. A random forest of 100 decision trees votes on each flower. Five-fold cross-validation scores both without touching the locked-away flowers.
    3. Take the exam once. The winner predicts the 30 held-out flowers, and the results above are what it got right and wrong.
    4. Predict your flower. Your four measurements go into the trained model, which returns a probability for each species.
    Data: Fisher's Iris dataset, 150 flowers and four measurements each. Everything runs as plain JavaScript on this page, with no server and no libraries. It is a port of a Python and scikit-learn project, so scores can differ slightly from the Python version.
